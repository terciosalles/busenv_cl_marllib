# busenv_cl_marllib
A plugin to transform the BusEnv environment in MARLlib into a Continual Learning setting, featuring metric tools and multiple training algorithms.
------------------------------------------------------------------------------------
To use the plugin, you must first complete all the installation steps for BusEnv; only after that initial installation is finished should you proceed with the steps to install the plugin itself.

Access the BusEnv link and perform the installation: https://github.com/LabIA-UFBA/BusEnv
------------------------------------------------------------------------------------------

This folder should be placed inside the MARLlib folder.

To install CL mode locally in developer mode:

python install.py -dev



To install CL mode in the MARLLib files directly in conda or in the installation directory:

python install.py
